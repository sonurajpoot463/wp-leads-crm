# WP Leads CRM

**WP Leads CRM** is a simple yet powerful WordPress plugin designed to help you manage leads efficiently. It allows website owners to collect, store, and track potential customer information directly from their WordPress dashboard.

## 🧩 Features

- Lead form shortcode for frontend collection
- Admin dashboard to view, edit, and delete leads
- Lead status tracking (New, In Progress, Converted, etc.)
- Export leads as CSV
- Compatible with all major themes
- Lightweight and easy to use

## 🛠️ Installation

1. Download or clone this repository.
2. Upload the folder to your WordPress site's `/wp-content/plugins/` directory.
3. Go to **Plugins** > **Installed Plugins** and activate **WP Leads CRM**.
4. Navigate to **Leads CRM** in the dashboard to start using it.

## 🔧 Usage

- Use shortcode `[wp_leads_form]` to display the lead capture form on any page or post.
- All submitted leads will appear under the **Leads CRM** menu in the admin dashboard.
- Change the lead status or export leads as needed.
